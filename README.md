Issue Tracking System

A full-stack Issue Tracking System developed using **Django REST Framework** and **Next.js**.  
The system provides a platform for users to create, manage, track, and update issues through a web-based interface.

Features

User Authentication

- User registration
- User login
- JWT-based authentication
- Authenticated API access
- Secure user session handling

 Issue Management

Users can manage issues through the application.
Main operations include:
- Create an issue
- View issues
- Update issue details
- Delete issues
- Track issue information

 Issue Details

An issue can contain information such as:
- Issue title
- Issue description
- Issue status
- Issue priority
- Assigned information
- Created/updated information

 REST API

The backend is implemented using Django REST Framework.
The frontend communicates with the backend through API endpoints for:
- Authentication
- User management
- Issue management
- CRUD operations
